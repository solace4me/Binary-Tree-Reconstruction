# Binary-Tree-Reconstruction
This project reconstructs a general binary tree (not a BST) using two traversal sequences:

In‑order traversal sequence

Post‑order traversal sequence

Using the theoretical property that these two sequences uniquely determine a binary tree, the program rebuilds the tree recursively, stores it in memory, and verifies correctness by re‑traversing the constructed tree.

**Implement:**

- A BinaryTree class
- A nested Node class
- Recursive inOrderTraversal() and postOrderTraversal() methods
- A static buildTree() method that reconstructs the tree
- A Tester class to validate correctness

This project is ideal for learning recursion, tree reconstruction, and traversal algorithms.

## Purpose of the Project
- To understand how traversal sequences define a unique binary tree.
- To practice recursive tree construction using array slicing and index tracking.
- To implement traversal methods that verify correctness.

## How to run
